How to land a real DoraHacks tx
════════════════════════════════════════════════════════════════════════
  1. Copy .env.example → .env and set KEEPERHUB_API_KEY=kh_...
  2. Create the key at https://app.keeperhub.com (org API keys).
  3. Connect a wallet integration and fund it on Base Sepolia (84532).
  4. Set KEEPERHUB_RECIPIENT_ADDRESS to a checksummed or lowercase address.
  5. Re-run npm run demo — simulate then execute_transfer, then record the tx hash.
  MCP (same key): https://app.keeperhub.com/mcp
